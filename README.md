# Meteorite Landings Analysis Solution

# Overview
This task performs a analysis of a meteorite landing dataset retrieved from a JSON source. The script downloads the dataset, processes the meteorite records, and extracts insights such as the total number of entries, the meteorite with the largest mass, and the year with the highest meteorite landings.

# Output
* Total number of meteorite.
* The name and mass of the most massive meteorite.
* The year with the most meteorite landings recorded.
